# Data handling

Use synthetic data for demonstrations. Keep exports, review workbooks, credentials, local configuration and authentication state outside Git. Do not commit real names, contact details, transaction identifiers or record IDs. Review every staged diff before publishing. The initial history contains only this curated portfolio snapshot.

Salesforce metadata and API names are illustrative integration contracts. Adapt them to a dedicated sandbox. Never run mutation scripts without reviewing their configuration, preflight results and scope.
